## 1. 安装与使用

### 1.1 安装方式

进入到工程目录并在 pubspec.yaml 中添加以下依赖：

<!-- tabs:start -->

#### pubspec.yaml

```yaml
dependencies:
  syncfusion_flutter_charts:
    git:
      url: https://gitcode.com/CPF-Flutter/fluttertpc_syncfusion_flutter_charts.git
      path: packages/syncfusion_flutter_charts   
```

执行命令

```bash
flutter pub get
```

<!-- tabs:end -->

使用案例详见 [ohos/example](./example/)
